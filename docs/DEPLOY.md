# Деплой на PythonAnywhere

Итог: бот [@InSiteBoGleb_bot](https://t.me/InSiteBoGleb_bot) работает через webhook на
<https://ipoderator.pythonanywhere.com>, панель — <https://ipoderator.pythonanywhere.com/admin>.

Всё, что требует вашего аккаунта и секретов, делаете вы (шаги 1–4). Остальное делает одна
команда. **Токены и пароли никому не пересылайте и не вставляйте в чат** — они живут только в
файле `.env` на вашем компьютере (он не попадает в git) и в `.env` на хостинге, куда его
кладёт скрипт.

## Что понадобится

- компьютер с Python 3.10+ и этим репозиторием (окружение — см. README, «Локальный запуск»);
- Telegram;
- email для регистрации на PythonAnywhere. Банковская карта не нужна.

## Шаг 1. Бот в @BotFather

1. Откройте [@BotFather](https://t.me/BotFather).
2. Новый бот: `/newbot` → имя → адрес на `_bot`. Бот уже есть (@InSiteBoGleb_bot) — тогда
   `/mybots` → бот → **API Token**.
3. Скопируйте токен (вида `123456789:AA…`) — он понадобится в шаге 4.

Если токен когда-нибудь попал в чужие руки: `/mybots` → бот → **API Token** → **Revoke**, новый
токен впишите в `.env` и повторите деплой (шаг 5).

## Шаг 2. Аккаунт PythonAnywhere (бесплатно, без карты)

1. Откройте <https://www.pythonanywhere.com> → **Pricing & signup** → **Create a Beginner
   account**.
2. Логин станет частью адреса: логин `ipoderator` → `https://ipoderator.pythonanywhere.com`.
3. Подтвердите email из письма.

Аккаунт в европейском регионе (`eu.pythonanywhere.com`) тоже подходит — адрес тогда
`https://<логин>.eu.pythonanywhere.com`, а в `.env` — `PA_HOST=eu.pythonanywhere.com`.

## Шаг 3. API-токен PythonAnywhere

1. Войдите на PythonAnywhere → правый верхний угол **Account** → вкладка **API token**.
2. **Create a new API token** → скопируйте токен.

Этим токеном скрипт деплоя загружает код и настраивает веб-приложение. На хостинг он не
копируется.

## Шаг 4. Файл `.env`

В корне проекта скопируйте `.env.example` в `.env` и заполните:

| Переменная | Что вписать |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из шага 1 |
| `TELEGRAM_WEBHOOK_SECRET` | можно оставить пустым — скрипт сгенерирует и сохранит на хостинге |
| `ADMIN_PASSWORD` | пароль панели, **не короче 10 символов** |
| `SECRET_KEY` | можно оставить пустым — скрипт сгенерирует |
| `DATABASE_PATH` | оставить пустым (на хостинге — `data/bot.sqlite3` в папке приложения) |
| `PUBLIC_BASE_URL` | можно оставить пустым — скрипт подставит адрес хостинга |
| `PA_USERNAME` | логин PythonAnywhere: `ipoderator` |
| `PA_API_TOKEN` | токен из шага 3 |
| `PA_HOST` | `www.pythonanywhere.com` (или `eu.pythonanywhere.com`) |

Сгенерированные секреты остаются на хостинге и при следующих деплоях берутся оттуда, поэтому
webhook и вход в панель не ломаются от повторного деплоя.

## Шаг 5. Деплой одной командой

Сначала пробный запуск — он ничего не отправляет в сеть, только показывает план и проверяет
`.env`:

```bash
.venv/bin/python scripts/deploy_pythonanywhere.py --dry-run
```

Затем деплой:

```bash
.venv/bin/python scripts/deploy_pythonanywhere.py
```

Скрипт по шагам (каждый — строка ✅ или ❌):

1. читает `.env` и проверяет его (имена переменных — да, значения — никогда не печатаются);
2. загружает код (`wsgi.py`, `requirements.txt`, `leadbot/`) в `/home/ipoderator/leadbot-app/`
   и серверный `.env` (без `PA_*`); `.venv`, `.git`, `.autopilot`, `data`, тесты, скрипты и
   документация не загружаются;
3. создаёт веб-приложение `ipoderator.pythonanywhere.com`, если его ещё нет (Python 3.11;
   другая версия — флаг `--python python310`);
4. пишет WSGI-файл `/var/www/ipoderator_pythonanywhere_com_wsgi.py`, включает принудительный
   HTTPS, перезапускает приложение и ждёт ответа `/health`;
5. ставит webhook `https://ipoderator.pythonanywhere.com/tg/webhook` с секретом и команды бота
   `/start`, `/menu`;
6. проверяет `getWebhookInfo`: адрес верный, ошибок доставки нет.

Flask и requests на PythonAnywhere уже установлены, отдельное виртуальное окружение не нужно.
Повторный запуск обновляет код; база с заявками и правками панели не трогается.

## Шаг 6. Получатель заявок: `/owner КОД`

1. Откройте панель <https://ipoderator.pythonanywhere.com/admin>, войдите с `ADMIN_PASSWORD`.
2. Раздел **Получатель заявок** — там команда вида `/owner AB12CD34`.
3. Отправьте её боту — в личном чате или в рабочей группе, куда вы добавили бота.
4. Бот ответит, что чат привязан; код после этого сменится сам. Кнопка **Тестовое сообщение**
   проверяет доставку. Пока получатель не привязан, заявки сохраняются только в панели.

## Шаг 7. Проверка на хостинге

Автоматическая проверка проходит короткую ветку анкеты на боевом адресе, сверяет заявку в
панели и проверяет, что правка текста из панели попадает в бота:

```bash
.venv/bin/python scripts/e2e_hosted.py --chat-id <chat_id>
```

- `chat_id` — ID вашего личного чата с ботом: он виден в разделе **Получатель заявок** после
  шага 6 («Личный чат, ID …»).
- Бот **по-настоящему ответит в этот чат** — вы увидите анкету с ответами «Тест
  Автопроверка», +7 900 000-00-00. Если этот чат — получатель, туда придёт и тестовая
  заявка. В панели она будет отмечена «Обработана».
- Во время проверки не пишите боту: скрипт определяет активное сообщение по счётчику
  сообщений чата (служебное сообщение «проверка связи» появляется и сразу удаляется).
- Скрипт временно меняет краткий заголовок вопроса «Текущее продвижение» в панели и в конце
  возвращает прежний текст.
- Ещё он проверяет `/health`, `getWebhookInfo`, флаг `Secure` у cookie панели и что вход с
  поддельным заголовком `X-Real-IP` не ломает сервер.

Затем ручная проверка по [CHECKLIST.md](CHECKLIST.md).

## Продление раз в 3 месяца (обязательно на бесплатном тарифе)

Бесплатное веб-приложение PythonAnywhere работает 3 месяца, затем отключается, если его не
продлить (данные не пропадают, но бот перестаёт отвечать).

1. Войдите на PythonAnywhere → вкладка **Web**.
2. Нажмите **Run until 3 months from today**.

PythonAnywhere присылает напоминание на email заранее. Продлевать можно в любой момент.

## Ограничения бесплатного тарифа (Beginner)

- одно веб-приложение на адресе `<логин>.pythonanywhere.com`, свой домен — только на платном
  тарифе;
- исходящие соединения — только на сайты из белого списка (`api.telegram.org` в нём есть);
- около 100 секунд процессорного времени в день на консоли и задачи; веб-приложение
  обслуживает запросы бота в пределах тарифа — для демо этого хватает с запасом;
- продление раз в 3 месяца (см. выше).

Условия тарифа PythonAnywhere могут меняться — актуальные на странице
<https://www.pythonanywhere.com/pricing/>.

## Если что-то пошло не так

| Симптом | Что сделать |
|---|---|
| ❌ `PythonAnywhere ответил HTTP 401` | неверные `PA_USERNAME` / `PA_API_TOKEN` / `PA_HOST`; создайте токен заново (шаг 3) |
| ❌ `/health не отвечает` | PythonAnywhere → **Web** → **Error log**: там причина. Частая — короткий `ADMIN_PASSWORD` или пустой токен |
| ❌ `getWebhookInfo: последняя ошибка доставки` | приложение отвечало ошибкой; посмотрите Error log и запустите деплой ещё раз |
| бот молчит | `/start` в чате; затем `e2e_hosted.py` покажет, какой шаг не проходит |
| заявки не приходят в Telegram | раздел **Получатель заявок** → **Тестовое сообщение**; заявки в любом случае есть в разделе **Заявки** |
| забыли пароль панели | впишите новый `ADMIN_PASSWORD` в локальный `.env` и запустите деплой |

## Запасной вариант: Render

Нужен, только если PythonAnywhere не подойдёт (например, тариф изменится). Решение и причина
фиксируются в отчёте.

1. Код — в репозиторий GitHub (публикация — только с вашего согласия).
2. <https://render.com> → **New** → **Web Service** → репозиторий.
   Build: `pip install -r requirements.txt gunicorn`, Start: `gunicorn wsgi:application`.
3. Переменные окружения — в настройках сервиса (те же, что в `.env`, без `PA_*`;
   `PUBLIC_BASE_URL=https://<имя>.onrender.com`).
4. Хранение: файловая система бесплатного сервиса Render не постоянная — SQLite-база
   пропадёт при перезапуске. Нужен постоянный диск (платно; `DATABASE_PATH` на этот диск)
   или Postgres — тогда меняется только модуль `leadbot/storage.py`.
5. Бесплатный сервис засыпает без запросов, первый ответ бота после паузы задерживается.
6. Webhook — той же функцией клиента бота (секреты не печатаются):

```bash
.venv/bin/python -c "from scripts.common import read_env_file as r; from leadbot.telegram import TelegramClient as T; e = r('.env'); T(e['TELEGRAM_BOT_TOKEN']).set_webhook('https://<имя>.onrender.com/tg/webhook', e['TELEGRAM_WEBHOOK_SECRET'], ['message', 'callback_query']); print('ok')"
```

Условия Render (карта, лимиты, цена диска) — уточнить на <https://render.com/pricing> на
дату перехода.
