# Telegram-бот заявок на сайты и продвижение

Бот сам проводит клиента по анкете из сценария заказчика (PDF, 28 страниц) — новый сайт,
доработка, продвижение, примеры работ, контакты, — показывает сводку ответов с возможностью
исправить любой и отправляет полную заявку владельцу в Telegram. Все заявки также видны в
защищённой веб-панели, где заказчик без программиста меняет тексты, контакты, ссылку на
политику, информационные блоки и примеры работ.

- Бот: [@InSiteBoGleb_bot](https://t.me/InSiteBoGleb_bot)
- Панель: <https://ipoderator.pythonanywhere.com/admin>
- Хостинг демо: PythonAnywhere (бесплатный тариф, без банковской карты)

Технология — собственное решение на Python: Flask (WSGI), `requests`, SQLite из стандартной
библиотеки. Без конструкторов и бот-платформ; webhook Telegram с проверкой секрета.

```

  config.py              настройки из окружения и .env
  storage.py             SQLite: настройки, тексты, сессии, заявки, примеры, попытки входа

  texts.py               все тексты бота по умолчанию (правки из панели — в базе)
  engine.py              конечный автомат диалога: одна точка входа handle_update
  leads.py               сводка, текст заявки, доставка владельцу
  validators.py          проверка имени, телефона, ссылок, текста, файлов
  telegram.py            тонкий клиент Bot API (токен не попадает в логи)
  web.py                 Flask: /tg/webhook, /health, /privacy, панель /admin

  e2e_hosted.py          проверка на боевом адресе
tests/                   автоматические тесты (pytest)
docs/                    документация
```

## Локальный запуск

Нужен Python 3.10+ (проверено на 3.11) и [uv](https://docs.astral.sh/uv/) (или обычный
`python -m venv` + `pip`).

```bash
uv venv .venv --python 3.11
uv pip install --python .venv/bin/python -r requirements-dev.txt
```

**Без Telegram — консольный чат.** `.env` не нужен, база временная:

```bash
.venv/bin/python scripts/run_local.py               # база удаляется при выходе
.venv/bin/python scripts/run_local.py --db data/local.sqlite3   # диалог сохраняется
```

Бот печатает сообщения и нумерует кнопки: число — нажать кнопку, любой другой текст —
отправить сообщение, `/файл` — отправить демо-файл ТЗ, `/выход` — выйти. Отправленная
заявка печатается с пометкой `[владельцу]`.

**Веб-панель локально.** Скопируйте `.env.example` в `.env` и заполните (минимум
`TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `ADMIN_PASSWORD` от 10 символов,
`SECRET_KEY`), затем:

```bash
.venv/bin/flask --app wsgi run
```

Панель — <http://127.0.0.1:5000/admin>. Webhook локально не работает (Telegram ходит только
на публичный HTTPS-адрес) — для диалога используйте консольный чат.

## Тесты

Одна команда:

```bash
.venv/bin/python -m pytest -q
```

Покрыто: каждый узел графа и каждый вариант с полем ввода, все ветки нового сайта,
продвижение с условиями и исключающими вариантами, доработка, финальный блок, сводка и
исправление (включая смену ветки), примеры и заказ из них, «Назад» с сохранением отметок,
устаревшие кнопки, повтор апдейта, перезапуск, доставка владельцу и её ошибки; панель
(вход и блокировка, CSRF, правка текстов меняет ответ бота, контакты, примеры, получатель,
заявки); webhook с неверным секретом; скрипты деплоя и проверки — с подменой сети.

## Деплой и проверка на хостинге

```bash
.venv/bin/python scripts/deploy_pythonanywhere.py --dry-run   # план, без сети
.venv/bin/python scripts/deploy_pythonanywhere.py              # деплой + webhook
.venv/bin/python scripts/e2e_hosted.py --chat-id <ваш chat_id>  # проверка на хостинге
```

Подробно — [docs/DEPLOY.md](docs/DEPLOY.md). Секреты живут только в `.env` (он в
`.gitignore`); скрипты не печатают их ни в каком режиме.
