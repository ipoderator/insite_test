## Что должно заработать

Одна команда разворачивает бота на PythonAnywhere из локального `.env` и ставит webhook. Вторая проверяет на боевом адресе, что бот отвечает, заявка сохраняется, а правка из панели применяется. Локальный консольный симулятор позволяет пройти ветки без Telegram. Документы для запуска, деплоя, проверки и для заказчика написаны; в черновике отчёта есть места под ссылки, время и расходы, которые финальная фаза заполнит фактами.

## Критерии приёмки

- [ ] `scripts/deploy_pythonanywhere.py` по API PythonAnywhere (`PA_USERNAME`, `PA_API_TOKEN`, `PA_HOST`) загружает код (без `.venv`, `.git`, `.autopilot`, `data`, тестов), загружает серверный `.env` (генерирует `TELEGRAM_WEBHOOK_SECRET` и `SECRET_KEY`, если их нет), создаёт веб-приложение, если его нет, пишет WSGI-файл, включает HTTPS, перезапускает, ставит webhook с секретом и команды бота, проверяет `/health` и `getWebhookInfo`; ни один секрет не печатается; есть `--dry-run`, протестированный без сети
- [ ] `scripts/e2e_hosted.py` шлёт на боевой webhook подписанные апдейты от указанного chat_id, проходит анкету до отправки, входит в панель и находит заявку, меняет текст в панели и проверяет, что новый текст ушёл (по ответу Bot API в логах приложения или по списку заявок/сессии через панель), затем возвращает текст
- [ ] `scripts/run_local.py` — консольный симулятор: печатает сообщения и кнопки, кнопка выбирается номером, текст вводится строкой
- [ ] `README.md`: что это, структура, локальный запуск, тесты одной командой, ссылки на документы
- [ ] `docs/DEPLOY.md`: точные шаги пользователя (BotFather, регистрация на PythonAnywhere без карты, API-токен, заполнение `.env`), команда деплоя, привязка владельца `/owner КОД`, продление бесплатного приложения раз в 3 месяца, запасной вариант Render
- [ ] `docs/ADMIN_GUIDE.md`: для заказчика без программирования — каждый раздел панели, что меняется и где видно в боте
- [ ] `docs/CHECKLIST.md`: краткая инструкция для проверки — шаги по всем веткам, «Назад», мультивыбор, сводка, исправление, отправка, панель
- [ ] `docs/REPORT.md` — черновик с 8 пунктами брифа и пунктами PDF стр. 2: платформа и технология, доп. функция и её польза, администрирование, расходы (демо 0 ₽; продакшн — вилки с обоснованием, 152-ФЗ), оценка стоимости разработки по часам; места для ссылок и фактического времени помечены `[ЗАПОЛНИТЬ]`
